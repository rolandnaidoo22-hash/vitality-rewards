# Vitality Rewards

A phone-first calculator for Discovery Vitality rewards (HealthyFood, HealthyCare, HealthyBaby, Fuel), with on-phone slip scanning.

Live app: https://vitality-rewards.chess-review.workers.dev/

All data stays in your browser (localStorage). Every rate and cap is editable in Settings.

Deploy: `npx wrangler deploy` (needs a Cloudflare API token in the environment).

Branch `gameboard` holds the unpublished Gameboard build.
